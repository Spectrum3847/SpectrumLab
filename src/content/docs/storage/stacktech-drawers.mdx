The StackTech towers are the shop's mobile tool storage: modular drawer units stacked on caster bases that roll to wherever the work is. Every drawer is labeled, every tool has exactly one drawer, and the whole system only works because everyone puts tools back where the label says.

<ToolProcurementCard tool="stacktech" />

## What StackTech Is

ToughBuilt StackTech is a modular stacking storage system — boxes, drawer units, and organizers that lock together with self-aligning tops, so a tower stays one unit when you roll it, tip it up a curb, or pull one drawer out at chest height.

| Spec | Detail |
| --- | --- |
| System | Modular stacking with self-aligning tops and steel-reinforced lids |
| Sealing | IP65 rated — dust-tight and water-resistant |
| Standard box capacity | 75 lb (large 21" box: 100 lb) |
| Drawer unit capacity | 50 lb |
| Rolling box capacity | 250 lb on 9" wheels |

That IP65 rating matters less in the shop and more at competition — the same drawer units travel to events without dumping hex keys into the trailer.

## The One Rule

<SafetyWarning type="warning" title="Tools go back in their labeled drawer">
Not on the bench. Not in your pit bag. Not in the "close enough" drawer. Every tool in these towers has exactly one home, and the label on the drawer is it. A tower with tools in the right drawers saves the whole team minutes on every task; a tower with tools scattered costs the whole team hours every week.
</SafetyWarning>

- **Take it, use it, return it** — same meeting, same drawer.
- Battery **out** before an M12 tool goes back in its drawer.
- If a drawer's contents don't match its label, fix it or flag it — don't relabel around the mess. Labels follow the [shop labeling standard](/storage/label-makers/).
- Broken or dull tools don't go back in the drawer to surprise the next person. Set them aside and tell a mentor, and note replacements on the [consumables ledger](/inventory/consumables/).
- Rolling a tower somewhere for a task is encouraged. Rolling it back at close is mandatory.
